# Chegolá?

**Site:** [https://chego-la.vercel.app](https://chego-la.vercel.app)

Aplicação web sobre pontos de alagamento em Itaúna/MG. Reúne uma referência histórica da Prefeitura e relatos locais, com mapa, ocorrências, formulário e a página Sobre o Projeto.

A rota do mapa avisa quando o caminho passa perto de um ponto cadastrado e, quando possível, mostra um desvio. Proximidade não confirma alagamento no momento e não substitui a Defesa Civil.

O código da aplicação e a documentação de instalação, dados e fluxos estão em [ChegoLa/README.md](ChegoLa/README.md).
